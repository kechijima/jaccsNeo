# システム修正・機能要望・検証事項タスクリスト

いただいたご要望および不具合・検討事項を、対象画面・機能ごとに整理したリストです。

---

## 1. 通知機能
- [ ] **通知履歴の自動削除機能**
  - 都度削除ではなく、一定期間（例: 1ヶ月）経過後に自動削除される仕様（検討・実装）。
  - 都度削除も検討
- [ ] **メール通知・Push通知機能の作成**

---

## 2. 活動報告画面・スペース関連
- [ ] **参加スペース枠の表示変更**
  - 右側の参加スペース枠に以下の項目を表示する。
    - Reteraceグループ活動報告
    - Miraitoグループ活動報告
    - Assetグループ活動報告
    - Reteraceグループ理事会報告
    - Miraitoグループ理事会報告
    - Assetグループ理事会報告
    - 中央理事会報告
  - 枠下に「すべてのスペースを表示」リンクを設置し、クリックでスペース一覧画面へ遷移できるようにする。
- [ ] **スペースのデザイン調整**
  - 各スペース内の「メンバー枠」を非表示/削除。
- [ ] **プロフィール写真の連動修正**
  - マイページでプロフィール写真を変更した際、活動報告画面のアイコンに正しく反映されるように修正。

---

## 3. マイページ・ユーザー設定
- [ ] **氏名変更の制限**
  - マイページで氏名が編集できてしまう（保存時に「なしなし」になる等の不具合）ため、一般ユーザーの氏名変更不可にする。
  - 氏名は登録時に設定されたものとし、管理者のみが変更可能な仕様に変更する。
- [ ] **サポート者入力欄の仕様変更**
  - 初期表示を2つに変更するか検討。
  - 入力ミス（誤字脱字）防止のため、組合員一覧からの選択方式への変更(コンボボックス)。
  - 「上司」という表記/選択肢を削除。

---

## 4. メンバー管理・権限
- [ ] **メールアドレス誤入力時の対応**
  - アドレスミス時に「脱退扱い」とならないよう、ユーザーの「削除ボタン」を新設、または「メールアドレス変更機能」を追加。
  ⇒Authユーザー作成にも影響するため、アドレス変更により不具合が生じないかも検討
- [ ] **同姓同名のユーザー検証**
  - 同姓同名のユーザーが存在する場合にシステム上問題が生じないか検証を実施。

---

## 5. アプリ申請・組合申請
- [ ] **組合申請とスペースの自動生成**
  - 組合申請の承認/登録と同時に、対応する組合のスペースが自動作成される仕組みを構築。
    ⇒申請時に同時にスペースを作成するかのチェックは入れるようにする
- [ ] **申請画面の組合管理者名（任意）フィルター**
  - 選択肢に脱退者が表示されるため、脱退者を除外して現役メンバーのみ選択できるように修正。
- [ ] **プロダクトアプリ申請の対象者選択**
  - 誰に対する申請（対象者）なのかをユーザーから選択(コンボボックス)できる項目を追加。

---

## 6. アプリ連携・個別の業務アプリ
- [ ] **アプリ連携画面**
  - アプリ名での検索機能を追加。
  - 過去に入力履歴がある場合、「過去入力有」等のフラグ・バッジを表示。
- [ ] **問い合わせ管理アプリ**
  - 詳細画面からコメント等を閲覧できる機能を追加。
- [ ] **プロダクトアプリ**
  - 画面上部の表記がモックデータのままになっているため、正式データ/動的表示に修正。
- [ ] **各アプリのデータ整理**
  - ダミーデータの削除。
  - 各アプリで表示されている「案件数」の数値不整合を修正。

## 7. 専門家・ディレクター・検索機能
- [ ] **専門家チーム**
  - 専門家チームに所属するメンバーを絞り込み（フィルタリング）表示できる機能を追加。
- [ ] **ディレクター逆引き機能**
  - 新規登録ユーザー（例: 岡駿 氏）が逆引き検索結果に表示されない不具合の修正。
